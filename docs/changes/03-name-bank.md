# 方案 03 — 随机昵称词库(nameBank)

> 范围:仅 `shabox-blog-web`。新建一个数据文件 + 一个 `rollName()` 生成器。
> 注册时自动 roll 一个昵称,用户不改就一直是它;之后可在账户里改。
> 风格:修饰词 × 称谓随机组合;**称谓多取自你爱的游戏黑话**。词你随时增删。

## 新建文件:`src/data/nameBank.js`

> 词典内容是我凭对各游戏的了解整理的,你按喜好增删——想加的直接告诉我或自己补。

```js
// src/data/nameBank.js

  "铁驭", "王牌铁驭",
  // —— 黑神话:悟空 ——
  "天命人", "大圣", "行者",
  // —— 只狼 ——

  "时间回溯者", "拍照客",
  // —— 站点自有 ——

const pick = (arr) => arr[Math.floor(Math.random() * arr.length)];

/**
 * 生成一个随机昵称。
 * @param {object} [opts]
 * @param {boolean} [opts.withSuffix=false] 末尾加 #4 位号(纯观感,昵称不要求唯一)
 * @returns {string}
 */
export function rollName({ withSuffix = false } = {}) {
  const useMod = Math.random() < 0.6; // 60% 概率带修饰词
  let name = useMod ? `${pick(NAME_MODS)}${pick(NAME_TITLES)}` : pick(NAME_TITLES);
  if (withSuffix) {
    const n = Math.floor(1000 + Math.random() * 9000);
    name = `${name}#${n}`;
  }
  return name;
}
```

## 用法(注册页会调)

```js
import { rollName } from "@/data/nameBank.js";

// 进注册页 roll 一个
const name = rollName();           // e.g. "像素薪王" / "铁驭" / "星河天命人"
// 想要 #号后缀: rollName({ withSuffix: true })  // e.g. "褪色者#4827"
```

## 说明 / 你来定的点

- **长度安全**:修饰(2–4)+ 称谓(2–6)≈ 4–10 字,远低于后端 `displayName` 上限 32。
- **#号后缀**:默认关。你想要就 `rollName({ withSuffix: true })`。纯观感,不强制唯一(displayName 在 schema 里非唯一)。
- **词库是内容物**:你想加哪个游戏的哪个称谓,直接告诉我或自己往数组里加,不影响生成器。
- 这个文件**纯前端**,改词不用动后端。
